                            EXAMPLE INDICATORS DETAILS
================================================================================

1. pine_script (EMA Crossover):
   - Type: Overlay indicator
   - Complexity: Beginner
   - Features: Dual EMAs, crossover signals, fill area, alerts
   - Use case: Trend following, entry signals
   - Fully documented with inline comments

2. rsi_indicator.pine:
   - Type: Oscillator
   - Complexity: Beginner
   - Features: RSI calculation, OB/OS zones, exit signals
   - Use case: Momentum trading, reversal detection
   - Customizable levels and periods

3. support_resistance.pine:
   - Type: Overlay indicator
   - Complexity: Intermediate
   - Features: Pivot detection, dynamic S/R levels, labels
   - Use case: Price action trading, level identification
   - Automatic level calculation

4. volume_profile.pine:
   - Type: Oscillator with table
   - Complexity: Intermediate
   - Features: Volume analysis, spike detection, info table
   - Use case: Volume confirmation, strength analysis
   - Color-coded volume bars

5. macd_advanced.pine:
   - Type: Oscillator with statistics
   - Complexity: Intermediate
   - Features: MACD calculation, histogram, statistics table
   - Use case: Trend following, divergence trading
   - Enhanced with visual aids
